    EXTRACTION DES DOCUMENTS

    Connexion à un modèle

    ✦
    Chargement…

    Pour extraire vos propres factures

    La connexion se configure sur le serveur. L’équipe technique choisit un des modes suivants, puis redémarre l’application.

    Claude (Anthropic)

    Configurez INVOICE_PROVIDER=anthropic, ANTHROPIC_API_KEY et, si nécessaire, ANTHROPIC_MODEL. Les documents sont transmis à ce fournisseur.

    Ollama

    Configurez INVOICE_PROVIDER=ollama, OLLAMA_BASE_URL et OLLAMA_MODEL avec un modèle capable de lire des images.

    Démonstration

    INVOICE_PROVIDER=demo reconnaît uniquement les trois documents d’exemple. Il ne consulte aucun modèle externe.

    Aucune clé API n’est saisie ni affichée dans cette interface. Les secrets restent dans la configuration du serveur.
